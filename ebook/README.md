# Prokrastynacja, która nie jest lenistwem

Kompletny ebook + strona sprzedażowa + kit marketingowy.

## Zawartość paczki

| Plik | Opis |
| --- | --- |
| `index.html` | Główny ebook (10 rozdziałów, 3 dodatki, interaktywny quiz) |
| `sprzedaz.html` | Strona sprzedażowa (landing) |
| `prokrastynacja-ebook.pdf` | Wersja PDF do pobrania (dla klientek) |
| `okladka.png` | Okładka 1200×1800 do use w kampanii |
| `KIT-SPRZEDAWCY.md` | Copy do e-maili, social, pitch |

## Struktura ebooka

**Część I — Zrozumienie**
- Wprowadzenie: scena z kuchni
- Jak korzystać z ebooka
- Rozdział I: To nie lenistwo — Strażak, Menedżerka, pętla prokrastynacji
- Rozdział II: Poznaj swój wzorzec oporu (test 5 profili)

**Część II — Cztery źródła oporu**
- Rozdział III: Mental Load i szum w głowie
- Rozdział IV: Perfekcjonizm paraliżujący
- Rozdział V: Ciało i cykle
- Rozdział VI: Dopamina i cyfrowe znieczulenie

**Część III — Działanie**
- Rozdział VII: Metoda CZUŁY START (7 kroków)
- Rozdział VIII: Narzędziownik (21 technik)
- Rozdział IX: Plan 21 dni
- Rozdział X: Kryzys i nawrót
- Rozdział XI: Rozmowy z otoczeniem
- Zakończenie

**Dodatki**
- A: 7 kart pracy do wydruku
- B: 12 najczęstszych pytań (FAQ)
- C: Bibliografia z poziomami dowodów

## Regeneracja plików

```bash
# PDF z HTML:
node /tmp/.../scratchpad/pdf.cjs

# Okładka PNG:
node /tmp/.../scratchpad/cover.cjs
```
